Neon Tide Cover Studio: an offline poster maker for GTA-style cover art. Drop in photos, pick one of eight panel layouts and a colour grade, set the title, and export a 16:9, square or 4:5 PNG. Plain static files, no library, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
